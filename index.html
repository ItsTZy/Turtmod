What's inside

Everything you'd bolt onto vanilla, in one mod.

Every feature is a module you can toggle, tune on its own settings page, bind to a key, and reset independently.

👁️

Visual clarity

  • Fullbright & low-fire overlay
  • Fog & screen-overlay control
  • Zoom, freelook, hurt-cam tuning
  • Block-outline recolor
  • Held-item size / position / rotation
⚔️

Combat feedback

  • Player health indicators — hearts or number
  • Reveals invisible / armor-only players
  • Hit color + armor-damage tint
  • Shield status recolor (usable / broken)
  • Custom entity hitboxes
🎛️

Movable HUD

  • Armor & potion HUDs
  • FPS/ping, reach, CPS, keystrokes
  • Coordinates, sprint, inventory, elytra
  • Clean F3 — tidy, reorderable debug screen
  • Drag every panel in the HUD editor
⚙️

Utility

  • Command-key macros (8 slots)
  • Kit loader — save & equip inventories
  • Mute sounds / hide particles pickers
  • Death coordinates
  • Gamemode switcher without op
🐢

Cosmetics

  • Skin changer with a live 3D preview
  • Drag to orbit, classic / slim models
  • Apply to your profile or import a file
  • Own-nametag & ping-on-nametag
💬

Chat, shots & more

  • Better chat — compact, timestamps
  • Screenshot gallery + one-click upload
  • Discord Rich Presence
  • ModMenu integration

Built to be tweaked

A config screen that feels like a launcher.

  • Native module grid — search, toggle, and open any module's settings. No third-party config library.
  • Drag-and-drop HUD editor — snap to grid or center, scale each element, reset in a click.
  • Custom theme — colors, borders, opacity, and text style shared across every panel.
  • Per-module reset and rebindable keys for everything.

Pick your version

Runs on 1.21.11, the 26.1 line, and 26.2.

One branch per Minecraft version. The 26.x builds need Fabric loader 0.19.3+ and a JDK 25 toolchain to build.

Latest

26.2

"Chaos Cubed" · Mojang-mapped
./gradlew build
branch master

26.1.x

26.1 / 26.1.1 / 26.1.2 — one jar covers all three
./gradlew build
branch 26.1

1.21.11

The proven base · intermediary-mapped
./gradlew :1.21.11:build
branch legacy/1.21.11

From source

Clone, build, drop in your mods folder.

The 26.x branches are unobfuscated (no remap step) and need a JDK 25 Gradle daemon; 1.21.11 uses Stonecutter with intermediary mappings.

# grab the code
git clone https://github.com/ItsTZy/Turtmod.git
cd Turtmod

# 26.2 (this branch) — jar lands in build/libs/
./gradlew build

# or the 26.1 line
git checkout 26.1 && ./gradlew build

# or 1.21.11
git checkout legacy/1.21.11 && ./gradlew :1.21.11:build
